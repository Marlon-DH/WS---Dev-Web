O que é HTML?

O HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para estruturar e organizar o conteúdo de páginas web. Ele define a hierarquia e o significado dos elementos que compõem uma página, como textos, imagens, links, tabelas, vídeos e formulários. Apesar de ser essencial para o desenvolvimento web, o HTML não é uma linguagem de programação, pois não permite criar lógica ou manipular dados diretamente.
